# 前端样式要求（AI 文档处理工作台）

> 本文档是前端 UI 实现的统一样式规范，供各页面 / 组件实现时参照。
> 技术栈：React 18 + TypeScript + Vite 5 + Ant Design 5.x（无额外 UI 库，不引入 CSS 框架 / CSS-in-JS 库）。

---

## 1. 整体风格

- **基调**：简洁、专业、清爽的办公工具风。以白色为主、灰白底背景 + 毛玻璃卡片、蓝色主题色，避免花哨装饰。
- **背景装饰**：页面背景为纯色灰白底（`--color-bg-page`）。不做渐变、不放置装饰色块——毛玻璃卡片仅提供轻微通透感（半透明白叠在灰底上），整体保持平实干净。
- **统一性**：所有页面共用 Layout（顶部导航 + 内容区 + 页脚），内容区页面之间视觉节奏一致。
- **响应式**：以桌面端为主（1280px+），内容区居中布局并限制最大宽度（1200px），在小屏（<768px）下不做破坏性布局（卡片换行、输入框保持可用即可），不做专门移动端适配。
- **语言**：界面文案全中文。

## 2. 设计令牌（Design Tokens）

在 `src/styles/global.css` 中统一定义 CSS 变量，页面与组件一律使用变量，禁止硬编码色值/圆角/阴影（AntD 组件本身的默认值除外，可通过 `ConfigProvider` theme token 覆盖）。

| 令牌 | 值 | 用途 |
| ------------------------- | --------------------------- | -------------------------- |
| `--color-primary` | `#1677ff` | 主题蓝（与 AntD 默认 primary 一致） |
| `--color-bg-page` | `#f5f5f5` | 页面背景（Layout.Content 区域） |
| `--color-bg-card` | `#ffffff` | 卡片 / 面板背景 |
| `--color-border` | `#d9d9d9` | 边框（AntD 默认 borderColor） |
| `--color-text-main` | `rgba(0, 0, 0, 0.88)` | 主文字 |
| `--color-text-secondary` | `rgba(0, 0, 0, 0.45)` | 次要文字（说明、辅助信息） |
| `--color-success` | `#52c41a` | 成功状态 |
| `--color-warning` | `#faad14` | 警告状态 |
| `--color-error` | `#ff4d4f` | 错误状态 |
| `--radius-md` | `8px` | 卡片 / 面板圆角 |
| `--radius-sm` | `6px` | 输入框等小控件圆角 |
| `--shadow-card` | `0 1px 2px rgba(0,0,0,0.03)` | 卡片阴影（弱化，平实为主） |
| `--space-page` | `24px` | 页面内边距 |
| `--glass-bg` | `rgba(255,255,255,0.72)` | 毛玻璃卡片底色（半透明白） |

| `--bg-decor-1` | `rgba(111,166,255,0.35)` | 背景装饰色块①（淡蓝，blur 处理） |

## 3. 布局

### 3.1 整体框架（Layout.tsx）

- 顶部 `Header`：AntD 默认深色（`theme="dark"`），`height: 64px`，左侧应用名「AI 文档处理工作台」（白色 18px/600 字重），右侧横向菜单（首页/文档问答/文档摘要/PDF 转 Word/大纲生成），当前路由对应菜单项高亮。
- 内容区 `Content`：`padding: 24px`，浅灰背景（`--color-bg-page`）。
- 页脚 `Footer`：居中灰色小字「AI 文档处理工作台 ©{年份}」。

### 3.2 页面内容区

- 功能页（问答/摘要/转换/生成）统一结构：**顶部操作区 + 结果展示区**，中间用 `Card` 承载。
- 首页用 4 个功能入口卡片铺排（与功能页卡片同款毛玻璃样式，见 4.2）。
- 内容最大宽度 1200px，居中（`margin: 0 auto`）。

## 4. 组件样式规范

### 4.1 页面标题

- 页面主标题：`<h2>`，`font-size: 22px; font-weight: 600`，下方留 `16px` 间距，不带装饰线。
- 卡片标题：AntD `Card` 自带 `title` 即可（16px/600），不额外加样式。
- 辅助说明文字统一用次要色（`--color-text-secondary`），13px。

### 4.2 卡片（Card）—— 毛玻璃风格

- **毛玻璃效果**（主效果，功能页卡片与首页入口卡片统一应用）：

  ```css
  background: var(--glass-bg);                      /* rgba(255,255,255,0.72) 半透明白 */
  backdrop-filter: blur(var(--glass-blur));         /* 12px 背景模糊 */
  -webkit-backdrop-filter: blur(var(--glass-blur)); /* Safari 前缀，必须同时写 */
  border: 1px solid var(--glass-border);            /* rgba(255,255,255,0.65) 半透明白边框 */
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-card);
  ```

- 卡片内边距：AntD 默认（`Card body` 24px）即可，不额外覆盖。
- **降级**：`backdrop-filter` 是渐进增强。不支持时（老浏览器/个别环境）卡片退化为普通白色卡片（半透明白底自动叠加在浅灰背景上，视觉依然干净），不额外写回退代码。
- 嵌套在毛玻璃卡片内部的元素（输入框、按钮、代码块等）**不再重复做毛玻璃**，保持自身实底或半透明即可，避免叠多层模糊导致视觉浑浊。

### 4.3 上传组件（FileUpload / Upload.Dragger）

- 拖拽区：虚线边框、`--radius-md` 圆角，背景用**半透明白**（`rgba(255,255,255,0.45)`，与毛玻璃卡片同属一个视觉层级，不做自身模糊）；居中显示上传图标（`InboxOutlined` 或 `CloudUploadOutlined`，48px）+ 主文案 + 次文案。
- 主文案「点击或拖拽文件到此区域」（14px/主文字色），次文案「支持 .pdf / .docx 文件，大小不超过 20MB」（12px/次要色）。
- 拖拽悬停（`hover`）时虚线边框变主题蓝、背景淡蓝（`rgba(22,119,255,0.06)`），提供明确可拖拽的视觉反馈。
- 上传成功后显示文件名称（`FileTextOutlined` 图标 + 文件名，主题蓝），可「重新上传」/「移除」。

### 4.4 按钮

- 主操作按钮（上传后的提问、生成摘要、开始转换、生成文档）一律用 AntD `Button type="primary"`。
- 次要操作（重置、重新上传）用 `type="default"` 或 `type="text"`。
- 主按钮尺寸：`size="large"`（操作区视觉重心），其余默认尺寸。

### 4.5 输入框

- 文本输入：AntD `Input`，默认尺寸，`placeholder` 用次要色。
- 问题输入：问答页用 `Input.TextArea`（`autoSize={{ minRows: 2, maxRows: 4 }}`），回车发送（`Shift+Enter` 换行）。
- 大纲输入（生成页）：`Input.TextArea`，`autoSize={{ minRows: 5, maxRows: 12 }}`，placeholder 示例「每行一条大纲，例如：`1. 项目背景`」。

### 4.6 加载状态（loading）

- 所有请求期间，操作按钮 `loading` 态（AntD 自带菊花图标），并提示文案：
  - 问答：按钮文案「回答中…」+ 回答区置灰或骨架屏。
  - 摘要：按钮文案「生成中…」+ 摘要区 `Spin` 居中。
  - 转换：按钮文案「转换中…」+ `Spin` + 提示「PDF 较大时可能需要一分钟」。
  - 生成：按钮文案「生成中…」+ `Spin` + 提示「文档生成可能需要 1-2 分钟」。
- 统一用 AntD `Spin` 组件，不手写动画。

### 4.7 结果展示

- **摘要文本**：`Card` 内正文，14px/1.8 行高，`white-space: pre-wrap` 保留换行；`Spin` 包裹加载。
- **问答回答**：`Card` 内 `react-markdown` 渲染，代码块/列表等由 markdown 默认样式展示；回答下方用 `Divider` 分隔「引用片段」（`sources`），每个引用用次要色小字标注「第 N 段」+ 引用文本块。
- **下载结果**（ResultDownload）：文件图标（`FileWordOutlined`，48px，主题蓝）+ 结果文件名 + `Button type="primary"`「下载文件」（`DownloadOutlined` 图标），整体居中对齐。
- **解析失败**：`Alert type="error"` 展示 `errorMessage`，并提供「重新上传」。

### 4.8 错误与提示

- 统一 AntD `message.error` / `message.warning` 提示，文案来自后端 `error.message`（如「文件解析失败：扫描件不支持」）。
- 页面级错误（如文件状态 `failed`）用 `Alert` 组件内联展示，不用弹窗。

## 5. 交互细节

- 上传后即可在主操作区交互（提问/生成摘要/转换），解析中（`status=uploaded/parsing`）主按钮禁用并提示「文件解析中，请稍候」，轮询 `GET /api/files/:fileId`（2s 间隔，最多 30s）直至 `parsed` 或 `failed`。
- 问答页提问后清空输入框；发送时若未上传文件或输入为空，`message.warning` 提示。
- 摘要/转换/生成操作完成后按钮恢复可用，结果区域展示新结果。
- 所有「下载」基于 `GET /api/download/:fileId`，点击下载不跳页。

## 6. 禁止事项

- 不引入 UI 组件库之外的 CSS 框架（Tailwind / Bootstrap 等），样式用 AntD 组件属性 + `global.css` 类名（BEM 风格，如 `.qa-page__input`）实现。
- 不在 JSX 中散落魔法色值；需要自定义色值时走 CSS 变量。
- 不用 `!important`。
- 不为纯展示功能引入动画库；如需过渡，用 CSS transition 即可。
